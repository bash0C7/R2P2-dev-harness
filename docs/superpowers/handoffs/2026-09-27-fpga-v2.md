## 作り (v2)

- 回路は速い道だけ (可変長のデコード、レジスタ、64bit の整数、メソッドの cache の当たりの呼び出し、配列の生成)。
  それ以外は **firmware** (fpga/firmware/*.rb、mruby ソースコード) を **罠** で呼ぶ (mruby の C の代わり)
- 参照 v2: `tools/fpga/v2/ref.rb` (回路のモデル、Ruby コード)。起動の像: `image.rb` (.mrb は変えずに並べる、コアのクラスと firmware の ROM のメソッド表、presym)
- 呼び出し: 特権の primitive の表 (`__fpga_*`、symbol で引く) → cache → 外れたら `__trap_lookup` (中は命令と `__fpga_*` だけ) → nil なら method_missing
- 回路に無い命令は `__op_<名前>(a, b, c)` の罠。firmware は `__fpga_reg` / `__fpga_setreg` で罠を起こしたフレームを読み書き
- 正しさの基準は host の PicoRuby (`rake fpga:oracle`、`rake fpga:v2:check`、`rake fpga:v2:fuzz[count,seed]`)。資源の関所は `rake fpga:synth` (V3 から)
